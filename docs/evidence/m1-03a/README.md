# M1-03A evidence artifacts

- `provider-capability-report.json`: machine-readable discovery report generated by
  `backend/cmd/m1-provider-capability` at the recorded UTC time.
- The report contains no auth token, raw response body, `drcp_`, or
  `APPLIED_VERIFIED` record.
- `jadm`/`drcp` are M1-00 evidence-slot names; `ajc_` is an
  M1-02A admission commit ID. This directory does not create or alias any of them.
